# Teaching Log App

This project contains two Streamlit applications:

- `app.py` — teaching reflection / post-teaching log system
- `project_app.py` — teaching project planning system

## Local run

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py --server.port 8501
streamlit run project_app.py --server.port 8517
```

## Render deployment

1. Push this project to GitHub.
2. Go to Render dashboard and create a new Web Service.
3. Connect the GitHub repository.
4. Use the included `render.yaml` file.
5. Render will deploy both apps automatically.

### Service URLs

- Teaching log app: `https://teaching-log-app.onrender.com`
- Teaching project app: `https://teaching-project-app.onrender.com`

The final URL will be generated by Render after deployment.

## Notes

- Use a valid Gemini API key in the app UI.
- Do not commit real secret keys.
- If you prefer to use environment variables, add them in the Render dashboard under Environment.

The app dependencies are listed in `requirements.txt`.
